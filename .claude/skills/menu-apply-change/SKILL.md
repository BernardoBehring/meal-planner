# Apply a change to the Menu

1. **Understand the change** and, if it is ambiguous, ask (e.g. "grilled or roast chicken?", "are the Guests coming for dinner or only lunch?", "are the Guests adults or children?").
2. Change the meal and those that depend on it (meal prep, ♻️ reuse).
3. Check the change keeps the Menu balanced and still uses ⚠️ Stock; if it affects a Child, run `menu-check-children`. If there is a conflict, explain and propose an alternative before applying.

Output: the new Menu, plus the ingredients that come in or go out.
