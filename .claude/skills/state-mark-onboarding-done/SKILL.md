# Mark onboarding done

In `data/state.md`:

- Top line: `Onboarding: DONE (YYYY-MM-DD)`.
- Remove onboarding from PENDING.
- BUDGET: set "Current month" to this month, remainder = monthly Budget.
- "Last updated".
