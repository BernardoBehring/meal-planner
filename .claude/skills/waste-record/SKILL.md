# Record Waste

Waste is food that went off or was thrown away without being eaten (a Leftover can still be used, so it is not Waste).

- WASTE in `data/state.md`: item, approximate quantity and value, date, cause if known.
- PRODUCTS → "Cause waste": the product, so the next Menus and Lists avoid it or buy smaller packs.
