# Economy mode

**The cost is always the cost of the adequate Menu.** Never save by reducing the amount of food needed, dropping important meals, removing fruit and vegetables without reason, reducing Children's essential foods, falling below the daily references, creating restrictive diets or putting price above nutritional adequacy. That turns a budget problem into a hidden food problem.

Apply, in this order (🟡: the easy ones only):

1. waste;
2. cheaper brands (store brand);
3. packs with a better price per kg/l;
4. cheaper equivalent products;
5. seasonal produce;
6. frozen;
7. reuse ingredients;
8. compare supermarkets (ask `price-research` for a comparison if it was not done);
9. only then change recipes and, last, the Menu.

Record each saving applied: `item → alternative: −amount`. Any change touching a Child goes through `menu-check-children`.

## If it still does not fit

**Do not hide the problem**: the Week is 🔴. Show the original cost, the cost after optimisation, the gap and where you saved, and present the **Scenarios** (Ideal, Economy, Minimum) only as differences from the main Menu — cheaper proteins, fewer premium items — each still meeting the daily references, without calling them "better" or "worse". The Lead decides; the Plan never decides silently.

A note like "fruit is tighter than usual this Week" means the sufficiency check failed: go back to `list-check-sufficiency` instead of writing it.
