# English internals, any country, shared as a Git repository

The system started as one Portuguese family's setup (Portuguese instructions, Portuguese supermarkets, euro, Windows only) and is now shared with families in other countries, speaking other languages, on Windows, macOS and Linux. We made English the internal language (agent, skills, glossary, data file headings) while the conversation and e-mails use whatever language the Family picks in onboarding; country, currency and supermarkets also come from onboarding, and scheduling has one script per operating system. It is distributed as a Git repository that each Family clones into a folder; `data/` and `inbox/` are git-ignored, so updates arrive with `git pull` without touching anyone's data. We rejected keeping Portuguese internals (others could not read or adapt the system), a per-country list of supported markets (too narrow), and a Claude Code plugin (the system lives in a folder with per-family data and OS schedulers, which a plugin handles poorly).
